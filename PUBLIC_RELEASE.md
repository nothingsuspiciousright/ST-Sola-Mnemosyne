# Public release content

This repository contains extension source code, generic interface text, and synthetic automated tests. It includes **no exported chat transcript, Memory Book, personal game-character names, API credentials, or account information**.

Do not commit your own memory exports, chat data, API keys, or local runtime archives to a public repository. Archive data is created only after installation and can be sent to an archivist provider selected by the installer.

Test fixtures use abstract labels such as `Agent Alpha` and `Zone C` and are not excerpts from a user's roleplay.

Version 0.3.4: small-batch JSON recovery for deep legacy indexing. Do not upload personal exports to GitHub.
